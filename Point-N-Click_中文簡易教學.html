1) 3分鐘快速上手

  1. 滑鼠停在某個按鈕上，先變黃，再變紅，表示「已選擇」該點擊模式。
  2. 把指標移到你要點擊的位置，停留到時間到，系統就會自動點擊。
  3. 如果不想點了，按 Cancel 取消。
兩個關鍵時間：
AutoSelect Delay = 在按鈕上停留多久才會選中按鈕。
AutoMouse Delay = 在目標位置停留多久才會真的點擊。

2) 設定選單總覽（Configuration）

File

  • Uninstall：解除安裝
  • Exit：關閉設定程式

Options（常用）

  • Run at Boot Up：開機自動啟動
  • Shortcut on Desktop：在桌面建立捷徑
  • Default to Left Click：每次點完自動回到左鍵模式
  • Visible When Active：執行點擊期間視窗保持可見
  • Visual/Audio Dwelling Feedback：停留時視覺/聲音提示
  • No Sound When Selecting/Clicking：關閉選擇/點擊提示音
  • AutoSelect Delay：設定按鈕選取延遲
  • AutoMouse Delay：設定實際點擊延遲
  • Sensitivity：設定抖動容忍度（建議先做）
  • Transparency：視窗透明度

Selections

  • AutoMouse Functions：決定主介面要顯示哪些按鈕
  • Remote AutoMouse Areas：設定遠端熱區
  • Initial AutoMouse Setting：啟動時預設選中的按鈕
  • Exclude Programs：排除不套用 Point-N-Click 的程式
  • Color Selection：變黃/變紅顏色調整

Macros

  • 啟用巨集、隱藏巨集面板、設定預設自動播放巨集

Help

  • 開啟說明與版本資訊

3) AutoMouse 點擊邏輯（核心觀念）

  • 按鈕選中後（紅色），下一次停留會觸發對應點擊。
  • 點擊完成後通常會自動取消選中（除非你設定預設回左鍵）。
  • 通常要先「移動離開主視窗」才會開始倒數點擊。
手冊提醒：在主視窗上亂停留可能誤觸，尤其左上/右上系統區域。

4) 進階點擊功能（常用版）

  • Shift / Ctrl / Alt：等同按住鍵盤修飾鍵再點擊
  • Repeat With Movement Required：每次移動才重複點擊（適合選單）
  • Repeat With No Movement Required：不移動也會依延遲連點（適合捲軸）
  • Fast Repeat With No Movement Required：最快速連點（只支援左/中/右鍵）
  • Right Click Then Left Click：先右鍵開選單，再左鍵選項
互斥關係：三種 Repeat 只能選一種。

5) 瀏覽網頁「向下捲動」建議設定

方法 A（最穩定）

  1. 選 Left Click
  2. 開啟 Repeat With No Movement Required
  3. 把指標停在瀏覽器右側捲軸下箭頭或捲軸區
  4. 會持續觸發點擊達到向下捲動效果

方法 B（部分瀏覽器可用）

  1. 選 Middle Click
  2. 在網頁空白處觸發中鍵自動捲動
  3. 指標往下移即可持續下捲
若太快/太慢，優先調整 AutoMouse Delay。

6) 視窗移動、Docking 與 Hiding

  • Move：用停留方式搬移主視窗。
  • Docking：自動吸附到螢幕左右邊。
  • Hiding：滑出後自動縮到邊緣，只留細邊可喚回。
  • Visible When Active：點擊執行期間不要自動隱藏（建議開）。

7) Remote AutoMouse Areas（遠端熱區）

  • 用途：全螢幕程式看不到主介面時，仍可透過桌面熱區觸發點擊。
  • 可自訂熱區位置與大小。
  • 建議先開 Show Remote AutoMouse Areas 做訓練。
Move / Dock / Hide / Help / Configure / Break Timer / Remote AutoMouse 不能設成遠端熱區。

8) 巨集（Macros）重點

  • Recording：錄製一串點擊順序（不記錄座標與時間）
  • Playback：一鍵回放點擊流程
  • Deleting：刪除不需要的巨集
因不綁定原始座標，重複性工作很實用。

9) 常見問題排除（簡易）

  1. 太容易誤點：提高 AutoMouse Delay，並先做 Sensitivity 測試。
  2. 選按鈕太慢：降低 AutoSelect Delay。
  3. 聽到太多聲音：開啟 No Sound When Selecting / No Sound When Clicking。
  4. 全螢幕不好操作：改用 Remote AutoMouse Areas。
  5. 介面按鈕太多：到 Selections → AutoMouse Functions 精簡。 （但 Left Click / Left Double Click / Move / Cancel 為必留按鈕）
